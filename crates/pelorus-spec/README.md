# pelorus-spec

Rust constants and URL helpers for the [**Pelorus Marine specifications**](https://github.com/pelorus-marine/specifications) repository (`MIT OR Apache-2.0`). Intended for host tooling, generators, and tests — browse normative prose under [`core/`](https://github.com/pelorus-marine/specifications/tree/main/core) and [`stream/`](https://github.com/pelorus-marine/specifications/tree/main/stream) on GitHub.

**MSRV:** Rust **1.88** (matches [`rust-toolchain.toml`](https://github.com/pelorus-marine/specifications/blob/main/rust-toolchain.toml)).
